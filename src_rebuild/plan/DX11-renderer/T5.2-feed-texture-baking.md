## Scope

Replace the DrawGame dx11 consumer's **untextured (white)** resolve with **real
texture baking**: the companion DX11 window now renders the terrain feed with
the game's actual PSX textures decoded from VRAM via `Dx11Tex_Bake`.

## Design

### UV ↔ region convention (the crux)

The game's `MODEL` UVs are **tpage-page-relative** (0..255), and the legacy GL
shader maps them into the page with a per-format X scale
(`v_page_clut.xy = (fract(page/16)*1024, floor(page/16)*256)`; 4-bit `*0.25`,
8-bit `*0.5`, 16-bit `*1.0` in X, `*1.0` in Y). So a tpage region is
**64/128/256 texels wide (by format) × 256 tall**.

`Dx11ModelAdapter` normalizes poly UVs by the **baked region size**. To sample
correctly, the feed must bake the **full page region** `(0,0,pageW,256)` and
**scale the model UV X by `pageW/256`** (V is 1:1) so the page-relative UVs land
in that region.
- pageW = 64 (4-bit) / 128 (8-bit) / 256 (16-bit), from `fmt = (tpage>>7)&3`.
- `Dx11GameFeed_ModelToMesh` gains a `tpages` param (the game's
  `texture_pages[128]`): when non-NULL it scales each converted poly's UV X by
  `pageW/256` derived from `tpages[set]`. NULL preserves the harness path
  (no scaling, untextured).

### Game-side resolve + VRAM

- `Dx11Game_TexResolve(set,id)` (main.c): `tpage = texture_pages[set]`,
  `clut = texture_cluts[set][id]`, region `(0,0,pageW,256)` (full page). OOB
  set/id → untextured (white).
- Every frame `Dx11Game_RenderFrame` refreshes the `Dx11Tex` VRAM staging from
  the game's VRAM (`GR_ReadVRAM` full 1024×512 → `Dx11Tex_CopyVRAM`), so
  spooled textures are present when first baked. The bake cache then reuses them.
- Texture cache cap raised to 512 (full-page bakes are one entry per page+clut).
