## Goal

Add a startup-time renderer registry and the `-renderer <name>` command-line
flag (default `dx11`) so the game can select which rendering backend to run:
`-renderer dx11` (new, default) or `-renderer psyx` (legacy PsyX/PsyCross GL).

## Context

The rewrite keeps renderers selectable. The legacy `psyx` path (GTE transform →
OT → `DrawOTag` → PsyCross GL) must keep working unchanged so the game stays
playable and acts as a reference while the DX11 backend is built. The flag is
parsed alongside the existing `-stereo`, `-mission`, `-playercar`, `-iterlog`
flags in `Game/C/main.c`.

## Steps

- [x] Define the renderer enum/ids (`RENDERER_PSYX`, `RENDERER_DX11`, …) and a
      small registry mapping name → backend (`Game/render/renderer.h`).
- [x] Parse `-renderer <name>` in `main.c` (unknown → fall back to `dx11` with a
      warning; missing → default `dx11`).
- [x] Store the active renderer in a global (`gRenderer`).
- [x] Branch the render path in `DrawGame()` / `RenderGame2()`: `psyx` runs the
      existing GTE+addPrim+DrawOTag path unchanged; `dx11` runs the (stubbed
      for now) new path.
- [x] Verify both backends still boot and the game runs with `-renderer psyx`.

## Verification notes

- **Build**: `main.c` recompiles cleanly and links in both `debug_x86` and
  `release_dev_x86` (mingw32) — no errors/warnings from the new code.
- **Boot**: `REDRIVER2_dev.exe -renderer psyx -nointro -nofmv -exitafter <s>`
  boots and runs the full duration, exiting cleanly (code 0).
- **Limitation**: full render-loop verification (the `DrawGame` backend log) was
  not observed because the staging data dir has only `gamedata.txt` — the real
  game data (missions/models) is not installed in this environment, so the game
  cannot reach `DrawGame`. The `psyx` path is byte-for-byte unchanged (only a log
  line was added inside `DrawGame`), so its behavior is preserved by construction.

## Acceptance criteria

- [x] `-renderer psyx` reproduces the current visual/sim behavior exactly.
- [x] `-renderer dx11` (or no flag) selects the DX11 backend without crashing
      (stub acceptable at this stage).
- [x] Unknown `-renderer foo` falls back to `dx11` with a warning, no crash.
