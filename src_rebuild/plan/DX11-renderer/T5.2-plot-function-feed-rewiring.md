## Goal

Rewire the game's **plot functions** — the render-producing functions in
`RenderGame2` (terrain/tiles, cars, sprites, sky, effects) — to **submit
`DrawCommand`s into the draw-command arena** (`drawcmd.h`/`drawcmd.c`) instead of
building the legacy GTE + `addPrim`/OT stream. This is the **feed (producer)
half** of the in-game path: real game geometry → `DrawCommand` list → the T5.1
renderer (`Dx11GameFeed_RenderFrame`) → per-eye → composite.

## Context

The renderer half is done (T5.1 `dx11_gamefeed` consumes a `DrawCommand[]` list
and renders it through the full DX11 pipeline). But no plot function `Submit`s
draw commands yet — they still do GTE transforms + `addPrim` into the ordering
table (the legacy psyx path). The T0.3 audit enumerated every `RenderGame2`
contributor and its pre-GTE world-space inputs (world transform + `MODEL` mesh +
material + z-bucket) — exactly what a `DrawCommand` needs. This task re-points
them to the feed.

**Verification caveat:** the full game does not reach the `DrawGame`/`RenderGame2`
gameplay loop headless in this environment, so the feed cannot be verified by
running the game. Each plot-function rewiring is verified by build-link +
inspection, and the end-to-end `DrawCommand` → renderer path is already proven by
T5.1's synthetic harness. A real in-game run (visual/log A/B vs `-renderer psyx`)
is the final gate and requires a user run.

## Design

For each plot function (in dependency order, starting with the terrain/tile core):

1. **Capture point**: at the point where the function currently has the world
   transform + `MODEL*` + material before GTE (from the T0.3 table), build a
   `DrawCommand`: `mesh = MODEL*`, `world` = the **world-space** transform
   (rotation `matrixtable[yang]`/`matrix` + world position `pos` — the renderer
   builds its own per-eye view from the camera, so `CompoundMatrix`/GTE
   camera-space transforms are NOT used), `material` from
   `texture_pages[set]`/`texture_cluts[set][id]`, `sortKey` from the existing OT
   bucket (`z>>1`/`z>>3`/`z>>8`), `flags` from the plot flags
   (`PLOT_TRANSPARENT`/`INV_CULL`/`NO_CULL`/`NO_SHADE`).
2. **Submit** via `DrawCmd_Submit` (returns the arena index). Keep the GTE+`addPrim`
   path for `-renderer psyx` (the feed is only consumed under `-renderer dx11`).
3. **BeginFrame**: call `DrawCmd_BeginFrame()` at the top of `RenderGame2` under
   `Renderer_IsDX11()`.
4. **Order**: terrain/tiles (`DrawMapPSX`/`DrawTILES`/`RenderModel`/`Plot*Model*`)
   first (the bulk), then cars (`DrawCar` chain), then sprites/sky/effects.
