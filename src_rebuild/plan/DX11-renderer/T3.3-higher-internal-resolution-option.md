# T3.3 — Higher internal resolution option

|            | |
------------|-|
| **Phase**  | Phase 3 — Color modes & split-screen |
| **Milestone** | M3 — Color modes & split-screen |
| **Status** | planned |

## Goal

Expose the configurable internal resolution (from T0.4) as a user-facing option,
so the game can render sharply above the PSX-native 320x240.

## Context

The DX11 renderer builds its own projection, so internal resolution is already
free (T0.4/T1.1). This task surfaces it: a `-res`/config option, and longer-term
the launcher GUI. It also verifies that higher-res rendering does not break the
projection (which it did in the PSX path).

## Steps

- [ ] Wire the internal-resolution config to the per-eye RTs (T1.1/T2.1).
- [ ] Add a CLI flag (`-res WxH`) and/or config key; validate supported values.
- [ ] Verify higher-res output is projection-correct (no top-left perspective
      centre, correct skybox).
- [ ] (stretch) Add the option to the launcher GUI (`src/Launcher/`).

## Acceptance criteria

- [ ] Rendering at e.g. 1280x720 internal is correct and sharp.
- [ ] The projection remains correct at higher res (unlike the PSX path).
- [ ] The option persists (config.ini) and is selectable.
