## Implementation

- **`Game/render/drawcmd.h`** — `DrawCommand` (mesh ref, `MATRIX world`,
  `MaterialRef material`, `sortKey`, `flags`, `palette`, `subdiv`),
  `MaterialRef` (tpage/clut + blend/state), `DrawCommandFlags` enum, and the
  per-frame buffer API. `#include`s `<types.h>`/`<libgte.h>`; `MODEL` is
  forward-declared.
- **`Game/render/drawcmd.c`** — growable arena (geometric growth, 1M-command
  cap): `DrawCmd_BeginFrame`/`Submit`/`Count`/`At`. `Submit` returns a stable
  index (realloc preserves indices).
- **Ownership split** written into the header and `PRODUCT.md`: the game keeps
  coarse PVS/cell culling + animation + LOD/subdiv; the renderer owns
  projection, frustum culling, depth sorting, material batching, and RT/composite.
- **Build**: `drawcmd.c` compiled and linked cleanly in `debug_x86` (mingw32);
  premake's `Game/**.c` glob picks up the new file automatically.
