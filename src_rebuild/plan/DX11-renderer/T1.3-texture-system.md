# T1.3 — Texture system: VRAM/tpage/clut → DX11 SRVs

|            | |
|------------|-|
| **Phase**  | Phase 1 — Core DX11 renderer |
| **Milestone** | M1 — Core DX11 renderer |
| **Status** | planned |

## Goal

Translate the PSX texture model (1024x512 VRAM, tpage/clut) into DX11
shader-resource views, reusing the existing tpage/clut decode math so visuals
match the legacy path.

## Context

Textures are paletted TIM data in a 1024x512 VRAM; `texture_pages[128]` /
`texture_cluts[128][32]` decode engine texture-set/id → tpage/clut. The legacy
path uploads the whole VRAM into one GL texture and samples via tpage/clut UVs.
The DX11 renderer must decide between a single VRAM atlas SRV vs. per-texture
SRVs, keeping the decode math (`GET_TPAGE_FORMAT`, `GET_CLUT_X/Y`, 4/8-bit
palette LUT) so output matches.

## Steps

- [ ] Port the TIM/VRAM upload path (`LoadImage`/`GR_CopyVRAM`) to DX11 texture
      creation (atlas or per-texture SRVs).
- [ ] Port the tpage/clut decode to compute UVs / palette indices in the shader
      (or bake palettes into the atlas).
- [ ] Handle 4-bit/8-bit paletted formats (RG8 LUT / palette texture) and the
      white 1x1 untextured substitute.
- [ ] Bind textures per material (`MaterialRef` from T0.2) in the DX11 pipeline.
- [ ] Verify a textured model matches the `psyx` output.

## Acceptance criteria

- [ ] Textured geometry renders with correct tpage/clut colors in DX11.
- [ ] 4-bit and 8-bit paletted textures both work.
- [ ] Visual output matches the `-renderer psyx` reference for the same scene.
