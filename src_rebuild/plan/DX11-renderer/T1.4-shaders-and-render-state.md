# T1.4 — Shaders + render state

|            | |
|------------|-|
| **Phase**  | Phase 1 — Core DX11 renderer |
| **Milestone** | M1 — Core DX11 renderer |
| **Status** | planned |

## Goal

Implement the DX11 shaders and render state that reproduce the PSX/PsyX
appearance: flat & gouraud shading, texture sampling, alpha/semi-transparency,
depth, blending, and the draw modes the game uses.

## Context

The legacy `Process*` handlers in `PsyX_GPU.cpp` distinguish flat vs gouraud
(bit 0 of the code), semi-transparency (bit 1), textured vs untextured, and
blend modes. The DX11 vertex/pixel shaders must cover these so the draw-command
paths from T0.3 render faithfully.

## Steps

- [ ] Vertex shader: world→view→projection (per-eye CB from T1.2), gouraud
      vertex colors, UVs.
- [ ] Pixel shader: flat vs gouraud color, texture sampling via tpage/clut
      (from T1.3), palette LUT, white-substitute for untextured.
- [ ] Blend + depth-stencil state objects matching the PSX semi-transparency
      and draw modes.
- [ ] Alpha/priority handling consistent with the OT depth sort keys.
- [ ] Shader hot-reload or at least compile-error surfacing for iteration.

## Acceptance criteria

- [ ] Flat and gouraud polys, textured and untextured, render correctly.
- [ ] Semi-transparent surfaces blend like the `psyx` reference.
- [ ] Depth is correct for opaque geometry (sorting handled in T1.5).
