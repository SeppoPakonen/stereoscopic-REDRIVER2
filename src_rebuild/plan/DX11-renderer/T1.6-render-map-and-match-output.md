# T1.6 — Render map/terrain + match visual output

|            | |
------------|-|
| **Phase**  | Phase 1 — Core DX11 renderer |
| **Milestone** | M1 — Core DX11 renderer |
| **Status** | planned |

## Goal

Wire the first real scenes through the DX11 renderer: the map/terrain and
static geometry, at whatever internal resolution, and verify the visual output
matches the `-renderer psyx` reference.

## Context

This is the first end-to-end visual milestone: the game's plot functions
(RenderModel / DrawTILES per the T0.3 audit) submit draw commands for the map
and static geometry, and the DX11 executor renders them. Matching `psyx` output
proves the texture, shader, state and projection work is correct.

## Steps

- [ ] Re-point the terrain/static-geometry plot functions to the draw-command
      list (T0.3 categories a/b), gated by `-renderer dx11`.
- [ ] Render the map/terrain and static geometry through T1.1–T1.5.
- [ ] Compare DX11 vs `psyx` output (same mission/camera) — sprite the two
      renderers beside each other and diff.
- [ ] Fix visual deltas (texture, shading, projection, culling, depth).
- [ ] Record the comparison method (a repeatable script/command) for regressions.

## Acceptance criteria

- [ ] Map/terrain + static geometry render correctly in DX11.
- [ ] Output matches `-renderer psyx` closely (minor acceptable deltas logged).
- [ ] A repeatable A/B comparison exists.
