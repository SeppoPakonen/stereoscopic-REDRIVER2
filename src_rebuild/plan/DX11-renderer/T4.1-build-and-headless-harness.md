## Goal

Keep the mingw32 build and the headless iteration harness working with the new
`-renderer` selection, so the DX11 stereo path is verifiable the same way the
legacy path was.

## Context

The rewrite must not break the established verification loop (mingw32 32-bit
build + gdb + opt-in `-iterlog`). The harness must be able to run both
`-renderer dx11` and `-renderer psyx`, and the build scripts must compile the
new DX11 sources (headers/libs available on the toolchain from T0.5).

## Steps

- [ ] Add the DX11 sources to the build scripts (`build_release_mingw32.sh` /
      `build_debug_mingw32.sh` / premake config) and the MSVC solution.
- [ ] Ensure `-renderer` is handled in the headless/iteration path (no window
      dependency for vector tests).
- [ ] Add a harness step that runs a mission under both renderers and logs
      per-eye draw counts + an A/B screenshot (from T1.6).
- [ ] Verify Release_dev and debug builds both link and run.

## Acceptance criteria

- [ ] `build_*_mingw32.sh` build the DX11 renderer with both renderers usable.
- [ ] The headless harness runs `-renderer dx11` and `-renderer psyx`.
- [ ] Build stays within the existing 32-bit toolchain.
