# T2.1 — Per-eye render targets

|            | |
------------|-|
| **Phase**  | Phase 2 — Stereo natively |
| **Milestone** | M2 — Stereo natively |
| **Status** | planned |

## Goal

Render each stereo eye to its own DX11 render target at the configured internal
resolution (no 320x240 lock), replacing the fragile shared-GL offscreen path.

## Context

The legacy path shares `g_offscreenRTTexture`/`g_offscreenRTTexture2` and runs
the right-eye bug (map disappears) downstream in GL rasterization. In DX11 the
offscreen RTs from T1.1 are per-eye from the start; each eye renders directly
into its own RT, so the shared-texture/resize fragility disappears.

## Steps

- [ ] Allocate a distinct RT (RTV+SRV) per eye at the internal resolution
      (reuse T1.1 offscreen RTs, one per eye).
- [ ] In the stereo render loop, bind the active eye's RT and render its
      draw-command list (per-eye camera from T2.2).
- [ ] Clear per-eye RTs correctly each frame; no cross-eye texture reuse.
- [ ] Keep the non-stereo path rendering to the backbuffer.

## Acceptance criteria

- [ ] Each eye renders into its own RT; contents are independent.
- [ ] No shared-texture resize bug (the `GR_ResetOffscreenSize` workaround is
      not needed here).
- [ ] Internal resolution per eye is configurable (T0.4).
