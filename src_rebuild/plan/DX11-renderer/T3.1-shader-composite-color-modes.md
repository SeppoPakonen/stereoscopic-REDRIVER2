# T3.1 — Shader-based composite color modes

|            | |

| **Milestone** | M3 — Color modes & split-screen |
| **Status** | planned |

## Goal

Implement the remaining stereo composite modes as a per-pixel shader pass:
anaglyph (simple + full-color), interlaced, polarized, checkerboard — building
on the fullscreen composite from T2.3.

## Context

The legacy shader compositor was implemented but disabled because it crashed
the GL driver. The DX11 composite pass (T2.3) is the natural place to add these
modes as pixel shader variants, avoiding the legacy GL shader path entirely.

## Steps

- [ ] Add a composite pixel shader that takes the two eye SRVs + a mode select.
- [ ] Implement the modes: anaglyph simple (red-cyan), anaglyph full-color,
      interlaced (odd/even rows), polarized (scanline encoding), checkerboard
      (pixel interleave).
- [ ] Wire each `gStereoMode` value to the matching shader variant.
- [ ] Verify each mode renders on-screen without driver crashes.

## Acceptance criteria

- [ ] All 6 non-disabled stereo modes from `gStereoMode` render correctly.
- [ ] No GL-driver crash (this is the DX11 path).
- [ ] Mode switching works at runtime / via `-stereo <mode>`.
