# T4.5 — Wire `-renderer gl` into the registry & build

|            | |
------------|-|
| **Phase**  | Phase 4 — Integration & cleanup |
| **Milestone** | M4 — Integration & cleanup |
| **Status** | planned |

## Goal

Add the **modern OpenGL backend** (T4.4's `gl_renderer` mono slice) to the
`-renderer` registry and the game build, so `-renderer gl` resolves and the
`DrawGame` dispatch genuinely selects it — mirroring how T4.1 wired `-renderer
dx11`.

## Context

The renderer registry (`Game/render/renderer.h`) currently knows only
`psyx` / `dx11` (`RENDERER_PSYX` / `RENDERER_DX11`, `Renderer_FromName` /
`Renderer_ToName` / `Renderer_IsPsyX` / `Renderer_IsDX11`). The modern GL
backend exists as the standalone `gl_renderer.{h,c}` module + `gl_nonstereo`
harness (T4.4), proven to render the same scene as DX11. This task brings it
into the registry and the game binary, so the three backends are all selectable
via `-renderer dx11|psyx|gl`. (The GL backend currently renders the mono scene;
per-eye stereo/composite parity remains a further follow-up.)

## Design

Mirror T4.1's slice — the full `DrawGame` → draw-command → GL render-path
rewiring is a later integration task; here we make the selection real and
observable:

1. **Registry** (`Game/render/renderer.h`): add `RENDERER_GL = 2`; resolve
   `"gl"` in `Renderer_FromName`; map it in `Renderer_ToName`; add
   `Renderer_IsGL()`.
2. **Capability probe**: add `GlRenderer_Available()` to `gl_renderer.{h,c}` —
   a lightweight SDL + GL context create/destroy probe (like
   `Dx11Renderer_Available()`), returning nonzero if the modern GL stack is
   usable on this machine. No window/rendering.
3. **Dispatch** (`main.c` `DrawGame`): the `Renderer_IsGL()` branch calls
   `GlRenderer_Available()` and logs the result (the mono path is used for now),
   mirroring the existing dx11/psyx dispatch.
4. **Build** (`premake5.lua` REDRIVER2): add `gl_renderer.{h,c}` +
   `PsyCross/src/render/glad.c` to the Windows build + `opengl32`/`SDL2` links +
   the mingw32 SDL2 include (via `MINGW32_SDL2_INCLUDE`, per the T4.4 gocha).
5. **A/B harness**: extend `dx11_rendererselect_test.cpp` to also resolve `gl`
   (`Renderer_FromName("gl") -> GL`, `Renderer_IsGL`) and probe
   `GlRenderer_Available()`.

- [ ] `-renderer gl` resolves to the modern GL backend (`Renderer_FromName("gl")`

- [ ] `DrawGame` genuinely dispatches on `-renderer gl` (calls
      `GlRenderer_Available()` and logs it).
- [ ] The game builds and links with the GL backend compiled in (32-bit mingw32),
      alongside dx11 and psyx.
- [ ] The renderer-select A/B harness verifies all three backends resolve.
