## Goal

Extend the modern GL backend (`gl_renderer`) with **per-eye offscreen render
targets (FBOs)** and a **fullscreen SBS/TB stereo composite** — mirroring the
DX11 stereo path (T2.1 per-eye RTs + T2.3 SBS/TB composite) — so `-renderer gl`
gains stereo parity with DX11. Verified headless with a self-probe harness.

## Scope (adjusted with the owner)

The draw-command-list GL stereo slice is the verifiable next step after T4.5.
This task delivers the **per-eye FBOs + SBS/TB/MONO composite** (the core stereo
composite, mirroring DX11 T2.1 + T2.3), verified headless by a harness that
renders a distinct scene per eye into the two eye FBOs and composites them into
the default framebuffer. The anaglyph/interlaced/polarized/checkerboard color
modes (DX11 T3.1) and split-screen (DX11 T3.2) are further follow-ups.

## Context

DX11 renders each eye into its own offscreen RT (T2.1) then composites eye0/eye1
into the backbuffer as SBS (eye0 left / eye1 right) or TB (eye0 top / eye1
bottom) with a swap option (T2.3). The GL backend (`gl_renderer`, T4.4) currently
renders only the mono path to the default framebuffer. This task adds the GL
equivalents: per-eye FBOs + a fullscreen-triangle composite shader (generated
from `gl_VertexID`, no VBO) sampling the two eye textures.

## Design

- **`gl_renderer.{h,c}`**:
  - `GlRendererConfig` gains `internalW`/`internalH` (per-eye FBO size; 0 = window).
  - Two per-eye RGBA8 textures + FBOs at the internal res.
  - `GlRenderer_BindOffscreen(eye)` / `GlRenderer_BindDefault()` — target selection.
  - `GlRenderer_BeginDraw()` (clear current target) + `GlRenderer_DrawQuads()` (draw
    to the current target) — refactored out of `RenderFrame` (which stays backward
    compatible).
  - `GlRenderer_GetEyeTexture(eye)` — the eye texture for the composite sampler.
  - `GlRenderer_Composite(mode, swap)` — a fullscreen-triangle composite (GLSL 150
    core VS from `gl_VertexID`, FS sampling eye0/eye1 with nearest sampler) drawing
    SBS/TB/MONO into the default framebuffer.
- **`spike/gl_stereo_test.cpp`** — harness: render a distinct full-screen scene per
  eye (eye0 red, eye1 blue) into the two eye FBOs, then composite and probe:
  `SBS` (left half red / right half blue), `TB` (top red / bottom blue),
  `SWAP` (swap flips the eye assignment), `MONO` (eye0 pass-through). Self-probes
  mirror the DX11 `dx11_composite_test.cpp` probes.
- **premake project `gl_stereo`** — `gl_renderer.{h,c}` + `gl_stereo_test.cpp` +
  `PsyCross/src/render/glad.c`; links `opengl32` + `SDL2`; include
  `PsyCross/include` + the mingw32 SDL2 dir (via `MINGW32_SDL2_INCLUDE`).

## Verification

`premake5 gmake2 --os=windows` + `mingw32-make gl_stereo config=release_dev_x86`
(32-bit). Run `bin/Release_dev/gl_stereo_dev.exe`. Writes
`gl_stereo_result.txt` + `gl_stereo.bmp` (the composite frame).

### Expected self-probe output (headless)

```
> gl_stereo_dev.exe                                          EXIT=0
  SBS  left(160,240)=red right(480,240)=blue PASS
  TB   top(320,120)=red bottom(320,360)=blue PASS
  SWAP left(160,240)=blue right(480,240)=red PASS
  MONO center(320,240)=red PASS
  TOTAL_FAILS=0 GLSTEREO=PASS
```

The GL eye FBOs + SBS/TB/MONO composite mirror the DX11 per-eye RT + composite
semantics (eye0 left/top, eye1 right/bottom, swap flips), establishing stereo
parity for `-renderer gl`. The refactored `gl_nonstereo` mono-path harness still
passes (no mono regression).

### Bugs found and fixed during verification

- **Composite eye-half selection was inverted**: the FS set `first =
  (uv.x < 0.5) ? 1 : 0` and sampled `first == 0 ? eye0 : eye1`, so the left/top
  half sampled eye1 instead of eye0 — the opposite of the DX11 composite (where
  `first` (left/top) selects eye0). SBS/TB/SWAP all failed (left was blue, right
  red); MONO passed only because it bypasses the half logic. Fixed to `first =
  (uv.x < 0.5) ? 0 : 1` (left/top → eye0), matching the DX11 semantics.
