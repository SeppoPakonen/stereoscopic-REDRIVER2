# T1.1 — DX11 device/context/swapchain + render targets

|            | |
|------------|-|
| **Phase**  | Phase 1 — Core DX11 renderer |
| **Milestone** | M1 — Core DX11 renderer |
| **Status** | planned |

## Goal

Create the DX11 device/context + a **native Win32 window + DXGI swapchain**
(not SDL2) for the `dx11` backend, plus render-target setup and the per-frame
RT management that Phases 2–3 build on.

## Context

The `psyx` backend keeps the SDL2 GL window. The `dx11` backend is a **native
DirectX stack**: window via Win32 `CreateWindowEx`, presentation via an
`IDXGISwapChain` (replacing `SDL_CreateWindow` + `SDL_GL_SwapWindow`), plus
device/context and render-target objects (backbuffer + offscreen RTs for
stereo). Platform/input/audio are covered by T1.7/T1.8. This task is the
foundation everything else in Phase 1 sits on.

## Steps

- [ ] Create `ID3D11Device`/`ID3D11DeviceContext` (feature level 11.0+).
- [ ] Create the Win32 window (`CreateWindowEx`) + `IDXGISwapChain` for the
      `dx11` backend (no `SDL_CreateWindow`); wire the message loop.
- [ ] Create backbuffer RTV + depth/stencil + viewport.
- [ ] Add offscreen `ID3D11RenderTargetView`/`ID3D11ShaderResourceView` = the
      internal-resolution RTs (reusable by T2.1 for per-eye).
- [ ] Implement present (`IDXGISwapChain::Present`) / clear and resize
      handling (e.g. `-res WxH`).
- [ ] Gate all of this behind `-renderer dx11` so `psyx` is unaffected.

## Acceptance criteria

- [ ] `-renderer dx11` creates device/Win32 window/DXGI swapchain and
      clears/presents a frame (no SDL2 window/GL context on this path).
- [ ] Offscreen RTs at configurable internal resolution (T0.4) exist.
- [ ] Resize and `-res` work; `-renderer psyx` is unchanged.
