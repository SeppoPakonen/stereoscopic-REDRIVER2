# T4.3 — Non-stereo regression

|            | |
------------|-|
| **Phase**  | Phase 4 — Integration & cleanup |
| **Milestone** | M4 — Integration & cleanup |
| **Status** | planned |

## Goal

Verify the DX11 renderer also renders the base (non-stereo) game correctly,
so stereo work does not regress normal play.

## Context

The DX11 renderer is the default for all modes, including monoscopic. The
non-stereo path must render the full game (map, cars, HUD, cutscenes, weather,
overlays) correctly. This is the final visual gate before the DX11 path can
fully replace psyx as default.

## Steps

- [ ] Run representative missions/scenes under `-renderer dx11` with stereo
      disabled; compare against `-renderer psyx`.
- [ ] Cover: map/terrain, cars, pedestrians, HUD/overlays, cutscenes, weather,
      debris, lens flare, split-screen (if implemented).
- [ ] Fix any DX11-only visual/behavioral regressions.
- [ ] Run the headless harness under both renderers and log a comparison.

## Acceptance criteria

- [ ] Base game renders correctly in DX11 with stereo off.
- [ ] No sim/behavior regression (frame logic unchanged).
- [ ] A/B comparison shows parity with `psyx` (minor deltas logged).
