## Goal

Composite the two per-eye RTs (T2.1) into the backbuffer as Side-by-Side or
Top-and-Bottom, driven by the stereo mode, replacing the GL `glBlitFramebuffer`
composite.

## Scope (adjusted with the owner)

The as-written T2.3 ("wire `gStereoMode` into the running DX11 renderer and
verify the composite matches the `psyx` SBS/TB output in-game") requires the
running game. Per the owner's decision (same as T1.6–T2.2), T2.3 is scoped to
the first verifiable slice: a **game-agnostic composite module + headless
harness** that samples the two per-eye offscreen SRVs (T2.1) into the
left/right (SBS) or top/bottom (TB) halves of the backbuffer, with a swap-eyes
option. Wiring the composite into the game's DX11 render loop (with the real
`gStereoMode`/`gStereoSwapEyes`) moves to the integration task (T2.4).

## Context

`StereoCompositor_Composite` (`Game/render/stereo_compositor.c`) blits the two
GL offscreen textures into the screen halves:
```
SBS: left eye -> dest (0,0,w/2,h), right eye -> dest (w/2,0,w,h)
TB : left eye -> dest (0,h/2,w,h), right eye -> dest (0,0,w,h/2)
```
The DX11 renderer does the composite itself — a fullscreen pass sampling the
two eye SRVs into the halves — which also sets up the per-pixel shader work for
Phase 3's color modes. `gStereoSwapEyes` swaps which eye fills the left/top
half.

## Design

`spike/dx11_composite.{h,c}` (game-agnostic; the game shim passes mode/swap and
the two eye SRVs):

- `Dx11Composite_Create(dev, ctx, result)` — compiles a composite VS (fullscreen
  triangle via `SV_VertexID`, no vertex buffer) + a PS that samples `t0` (eye0)
  / `t1` (eye1) into the halves, plus a `b0` params CB (`mode`, `swap`), a point
  sampler, a no-cull rasterizer and a depth-disabled state.
- `Dx11Composite_Composite(c, ctx, mode, swap, eye0, eye1, w, h)` — binds the
  composite shaders, sets `t0`/`t1` + sampler, updates the params CB, sets the
  viewport to `w×h` and draws the 3-vertex fullscreen triangle.
- Modes: `DX11C_MODE_SBS` (left half = eye0, right = eye1), `DX11C_MODE_TB`
  (top half = eye0, bottom = eye1), `DX11C_MODE_MONO` (pass-through of eye0
  across the full screen). `swap=1` swaps which eye fills the left/top half.

The harness (`spike/dx11_composite_test.cpp`), reusing the T2.1 eye-RT setup:
- renders a distinct colour quad per eye into offscreen RT 0/1,
- composites into the backbuffer and captures a BMP per (mode, swap),
- probes: `SBS_L`/`SBS_R` (left/right half colours), `TB_T`/`TB_B` (top/bottom
  half), `SWAP` (swap flips which eye is left/top), `MONO` (pass-through).

## Verification

`premake5 gmake2 --cc=gcc` + `mingw32-make dx11_composite config=release_x86`
(32-bit; mingw32 runtime DLLs beside the exe). Run `bin/Release/dx11_composite.exe`.
Writes `dx11_composite_result.txt` (sbs / tb / swap / mono probes).

### Actual observed output (mingw32 32-bit, release_x86)

```
dx11_composite_result.txt:
   SBS_L left-half(bx,cy)=(220,0,0) red PASS
   SBS_R right-half(bx,cy)=(0,0,220) blue PASS
   TB_T top-half(cx,by)=(220,0,0) red PASS
   TB_B bottom-half(cx,by)=(0,0,220) blue PASS
   SWAP SBS left=blue right=red PASS
   SWAP TB top=blue bottom=red PASS
   MONO full=(220,0,0) red (eye0 pass-through) PASS
   TOTAL_FAILS=0 COMPOSITE=PASS
```

The composite samples the two per-eye offscreen SRVs into the backbuffer halves
exactly as the legacy `StereoCompositor_Composite` lays them out (SBS: eye0
left / eye1 right; TB: eye0 top / eye1 bottom), independent of the backbuffer
resolution (halves are computed in the composite shader from the output
position). `swap` flips which eye fills the left/top half. The point sampler +
fullscreen triangle give the same nearest-neighbour upscale the legacy
`glBlitFramebuffer(..., GL_NEAREST)` used.

### Bugs found and fixed during verification

One harness bug (not in the module): `RenderEye` copied the world identity into
`it.world` with `memcpy(..., sizeof(ident))`, but `ident` is a function
parameter (`const float ident[4][4]` decays to a pointer), so `sizeof` was the
pointer size (4 bytes) instead of 64 — the world matrix past the first row was
garbage. Fixed to `memcpy(it.world, ident, 16 * sizeof(float))`. The composite
module itself (shader + swap logic) was correct on the first build.
