# T2.3 — SBS/TB composite in the renderer

|            | |
------------|-|
| **Phase**  | Phase 2 — Stereo natively |
| **Milestone** | M2 — Stereo natively |
| **Status** | planned |

## Goal

Composite the two per-eye RTs (T2.1) into the backbuffer as Side-by-Side or
Top-and-Bottom, driven by the stereo mode, replacing the GL `glBlitFramebuffer`
composite.

## Context

The legacy `StereoCompositor_Composite` blits the two GL offscreen textures
into the screen halves (SBS/TB). The DX11 renderer does the composite itself
from its two eye SRVs — a fuller-screen quad with the two eye textures — which
also sets up the per-pixel shader work for Phase 3's color modes.

## Steps

- [ ] Implement a fullscreen composite pass that samples the two eye SRVs into
      the left/right (SBS) or top/bottom (TB) halves.
- [ ] Wire `gStereoMode` (DISABLED/SIDEBYSIDE/TOPBOTTOM) to select composite vs
      pass-through.
- [ ] Handle `gStereoSwapEyes` (swap which eye is left/right).
- [ ] Verify the composite matches the `psyx` SBS/TB output.

## Acceptance criteria

- [ ] SBS and TB composite correctly from the two DX11 eye RTs.
- [ ] Swap-eyes swaps the sides/top-bottom.
- [ ] Output matches the legacy composite (aside from resolution).
