# T4.4 — (stretch) Modern OpenGL backend mirroring DX11

## Goal

Add a **modern OpenGL backend** (`-renderer gl`) that mirrors the DX11
architecture — a standard renderer stack (VAO/VBO/IBO, shaders, own projection),
NOT the legacy PsyX PSX-primitive model — so GL is not tied to the PSX OT/
primitive stream.

## Scope (adjusted with the owner)

The full T4.4 ("GL backend with per-eye RTs + composite parity with DX11, wired
into `-renderer gl`") is a large, mostly-unverifiable-in-one-slice stretch. Per
the owner's decision, T4.4 is scoped to the first verifiable slice: a **modern
GL mono-path module + A/B harness** — a standalone OpenGL renderer module
(`gl_renderer`) that renders the same common world-state scene as the DX11
backend through a modern GL 3.3 core pipeline (SDL window + glad loader,
VAO/VBO/IBO, GLSL shaders, orthographic screen→NDC projection, framebuffer
capture), and an A/B against the **DX11 backend** proving both reproduce the
identical scene. This proves the GL backend renders the draw-command-list scene
like DX11 without the PSX primitive model. Per-eye stereo/composite parity and
the `-renderer gl` registry wiring are deferred follow-ups.

## Context

The renderer abstraction (T0.1) and the draw-command list (T0.2) are
backend-agnostic, so a GL backend reuses the same scene feed and swaps only the
API layer. The environment already has a modern GL path: PsyCross creates an
SDL window + **OpenGL 3.3 core-profile** context and loads **glad**
(`gladLoadGL()`, `PsyCross/include/PsyX/common/glad.h` + `src/render/glad.c`,
gl=3.1 compatibility, standalone). mingw32 links `opengl32` + `SDL2`. So the
modern GL mono slice is fully buildable and verifiable headless here.

## Design

- **`spike/gl_renderer.{h,c}`** — a game-agnostic **modern GL renderer module**
  (the GL mirror of the DX11 mono path): SDL window + GL 3.3 core context,
  glad loader, a VAO + interleaved pos/color VBO + indexed EBO, a GLSL 150 core
  VS/FS pair, an orthographic screen→NDC projection (column-major, y-flip), a
  per-frame render of a list of screen-space flat quads directly to the default
  framebuffer, and a `glReadPixels` → BMP capture (before swap). No fixed-function,
  no PSX primitives.
- **`spike/gl_nonstereo_test.cpp`** — harness: renders the T4.2 common
  world-state scene (`dx11_backendab_state.h`, same default scene the DX11
  backend renders) through the GL mono path, and A/B's it against a DX11
  reference BMP (produced by the existing `dx11_backendab_dx11` binary).
- **premake project `gl_nonstereo`** — `gl_renderer.{h,c}` + `gl_nonstereo_test.cpp`
  + `dx11_backendab_state.h` + `PsyCross/src/render/glad.c`; includes
  `spike` + `PsyCross/include` (glad) + the mingw32 SDL2 dirs; links
  `opengl32` + `SDL2`.

## Verification

`premake5 gmake2 --os=windows` + `mingw32-make gl_nonstereo config=release_dev_x86`
(32-bit). Run `bin/Release_dev/gl_nonstereo_dev.exe` at 320x240 (the PSX native
res, matching the DX11 reference). Writes `gl_nonstereo_result.txt` +
`gl_nonstereo.bmp`. The DX11 reference is produced by the T4.2/4.3 DX11 backend.

### A/B with the DX11 backend (headless)

```
> dx11_backendab_dx11_dev.exe -store -state scene.bin -shot dx11.bmp   (T4.2 DX11)
> gl_nonstereo_dev.exe -dx11ref dx11.bmp                                EXIT=0
  GL   quad0 centroid(32,120)=(220,20,20) expect(220,20,20) PASS
  GL   quad1 centroid(160,120)=(20,200,40) expect(20,200,40) PASS
  GL   quad2 centroid(288,120)=(30,60,220) expect(30,60,220) PASS
  FULL_FRAME leftbar(32)=ok rightbar(288)=ok centersq(160)=ok PASS
  DX11 quad0 centroid(32,120)=(220,20,20) expect(220,20,20) PASS
  DX11 quad1 centroid(160,120)=(20,200,40) expect(20,200,40) PASS
  DX11 quad2 centroid(288,120)=(30,60,220) expect(30,60,220) PASS
  DX11_PARITY 3/3 centroids match dx11.bmp PASS
  TOTAL_FAILS=0 GLMONO=PASS
```

The modern GL backend and the DX11 backend both reproduce the identical scene —
same quads, same positions, same colours, to the exact byte — from the same
world-state, each through its own standard projection (GL ortho column-major vs
DX11 `P^t` screen→NDC). The GL backend is a standard renderer stack (SDL + GL
3.3 core + glad, VAO/VBO/IBO + GLSL shaders), not the PSX primitive/OT model.

### Bugs found and fixed during verification

- **premake `.."/SDL2"` path mangling**: premake's Lua `..` string concat of
  `(os.getenv("MINGW32_INCLUDE") or …) .. "/SDL2"` renders the include dir with a
  stray space (`-I"I:/msys64/mingw32/include /SDL2"`) → `SDL.h not found`. The
  same line exists in the REDRIVER2 project but is masked there because the game
  doesn't `#include <SDL.h>` directly. Fixed by preferring a dedicated
  `MINGW32_SDL2_INCLUDE` env var (whose value already holds the dir and renders
  cleanly), with the concat as a best-effort fallback.
