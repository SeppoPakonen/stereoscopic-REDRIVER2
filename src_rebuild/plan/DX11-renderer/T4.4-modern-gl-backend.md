# T4.4 — (stretch) Modern OpenGL backend mirroring DX11

|            | |
------------|-|
| **Phase**  | Phase 4 — Integration & cleanup |
| **Milestone** | M4 — Integration & cleanup |
| **Status** | planned |

## Goal

Add a modern OpenGL backend (`-renderer gl`) that mirrors the DX11 architecture
— same draw-command list, same renderer-owned features (projection, culling,
sort, batch, per-eye RTs, composite) — so GL is not tied to the PSX primitive
model.

## Context

The owner wants a GL option that follows the "standard renderer stack" design
rather than the legacy PsyX path. Because the renderer abstraction (T0.1) and
the draw-command list (T0.2) are backend-agnostic, a GL backend can reuse the
task list's scene feed and only swap the API layer.

## Steps

- [ ] Define the renderer abstraction API surface so DX11 and GL share the
      draw-command feed (refactor if needed).
- [ ] Implement a modern GL backend (VAO/VBO/IBO, shaders, textures, FBOs for
      per-eye RTs, composite) mapping to the same draw-command list.
- [ ] Add `-renderer gl` to the registry.
- [ ] Match output to the DX11 backend (A/B).

## Acceptance criteria

- [ ] `-renderer gl` renders the draw-command list like DX11.
- [ ] GL backend supports per-eye stereo / composite modes (parity with DX11).
- [ ] Non-Windows portability is possible (unlike DX11).
