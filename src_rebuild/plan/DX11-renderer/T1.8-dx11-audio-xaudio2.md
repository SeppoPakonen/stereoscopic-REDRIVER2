# T1.8 — DX11 audio (XAudio2)

|            | |
------------|-|
| **Phase**  | Phase 1 — Core DX11 renderer |
| **Milestone** | M1 — Core DX11 renderer |
| **Status** | planned |

## Goal

Provide an **XAudio2** audio backend for the DX11 path. Audio is currently
OpenAL-only (`PsyCross/src/audio/PsyX_SPUAL.cpp`, `utils/audio_source/`); the
DX11 backend swaps it to XAudio2 as part of the "pure DirectX" goal. OpenAL
stays for the GL backends.

## Context

Audio is already decoupled from SDL2 (it is OpenAL, not SDL_mixer/`SDL_audio`).
This task is only about the DX11 "native DirectX" goal: a shared sound-source
abstraction implemented on XAudio2 for DX11 and OpenAL for GL. The PSX SPU
emulation (`PsyX_SPUAL.cpp`) is the main consumer to port.

## Steps

- [ ] Define a shared sound-source/device abstraction (create device, create
      buffer, play/stop, set volume/pan) with an XAudio2 implementation for
      DX11 and the existing OpenAL implementation for GL.
- [ ] Implement the XAudio2 backend: `IXAudio2` engine, master voice, source
      voices, XAudio2 buffers from WAV data.
- [ ] Port the PSX SPU emulation (`PsyX_SPUAL.cpp`) to the shared abstraction
      (channels, voices, effects such as reverb via XAudio2/X3DAudio if needed).
- [ ] Port the WAV/OpenAL sources in `utils/audio_source/` to the abstraction.
- [ ] Verify gameplay audio works under `-renderer dx11`; `psyx` keeps OpenAL.

## Acceptance criteria

- [ ] Game audio (SFX + music/streamed) works under `-renderer dx11` via XAudio2.
- [ ] The game's audio consumers are unchanged (only the backend differs).
- [ ] `-renderer psyx` still uses OpenAL, unaffected.
