# T3.2 — Split-screen

|            | |
------------|-|
| **Phase**  | Phase 3 — Color modes & split-screen |
| **Milestone** | M3 — Color modes & split-screen |
| **Status** | planned |

## Goal

Implement split-screen: 2 players × 2 eyes = 4 images, user-selectable
horizontal/vertical split, composited in the DX11 renderer.

## Context

The renderer already supports multiple render-targets and per-eye views. Tagging
each eye's composite quad with a screen quadrant (player × eye) turns the
composite pass into a 4-viewport layout. The game's `MPBuff[2][2]` already
double-buffers per player, so the per-player scene data is available.

## Steps

- [ ] Define the split layout (2 players; h or v split) as a config/flag.
- [ ] Render 4 viewports (player1-eyeL, player1-eyeR, player2-eyeL,
      player2-eyeR) into the backbuffer quadrants.
- [ ] Wire per-player camera + per-eye projection into each viewport.
- [ ] Support combining split-screen with the Phase-3 color modes if desired.

## Acceptance criteria

- [ ] 2-player split-screen renders 4 images correctly (h and v split).
- [ ] Each player's eyes are correct (lateral offset, no cross-contamination).
- [ ] Splits are user-selectable at runtime / via flag.
