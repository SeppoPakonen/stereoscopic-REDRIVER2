# Phase 3 Task #10: Technical Reference - Render-to-Texture Anaglyph Composition

## Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                     DrawGame() Main Loop                 │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  For Anaglyph Modes:                                     │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 1. BeginEyeRender(LEFT) → Bind Left FBO          │  │
│  │    RenderGame2(0)        → Render to texture     │  │
│  │    EndEyeRender()        → Unbind FBO            │  │
│  └──────────────────────────────────────────────────┘  │
│                                                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 2. BeginEyeRender(RIGHT)→ Bind Right FBO         │  │
│  │    RenderGame2(0)        → Render to texture     │  │
│  │    EndEyeRender()        → Unbind FBO            │  │
│  └──────────────────────────────────────────────────┘  │
│                                                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 3. Composite()           → Apply shader          │  │
│  │    - Bind backbuffer (FBO 0)                     │  │
│  │    - Bind anaglyph shader                        │  │
│  │    - Set texture uniforms                        │  │
│  │    - Render fullscreen quad                      │  │
│  └──────────────────────────────────────────────────┘  │
│                                                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 4. SwapDrawBuffers()     → Display result        │  │
│  └──────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

## Data Structures

### STEREO_COMPOSITOR

```c
typedef struct {
    // Texture and framebuffer resources
    uintptr_t left_eye_texture;         // OpenGL texture for left eye
    uintptr_t right_eye_texture;        // OpenGL texture for right eye
    uintptr_t left_eye_fbo;             // Framebuffer object for left eye
    uintptr_t right_eye_fbo;            // Framebuffer object for right eye

    // Shaders for different stereo modes
    uintptr_t anaglyph_shader;          // Simple red-cyan anaglyph
    uintptr_t anaglyph_fullcolor_shader;// Full-color anaglyph with color matrix
    uintptr_t sidebyside_shader;        // Side-by-side composition
    uintptr_t topbottom_shader;         // Top-bottom composition
    uintptr_t interlaced_shader;        // Interlaced scanline composition

    // Fullscreen quad geometry
    uintptr_t fullscreen_quad_vao;      // Vertex array object for quad
    uintptr_t fullscreen_quad_vbo;      // Vertex buffer object for quad

    // Configuration
    int width;                          // Screen width in pixels
    int height;                         // Screen height in pixels
    int initialized;                    // 1 if initialized, 0 otherwise
    int use_render_to_texture;          // 1=enabled, 0=fallback to double render
    float last_composite_time;          // Performance tracking (ms)
} STEREO_COMPOSITOR;
```

### Framebuffer Object (FBO) Details

Each FBO is bound to a texture:
```
Left Eye FBO:
├── Color Attachment 0 → left_eye_texture (1024x768 RGBA)
├── Depth Buffer (generated by glClear)
└── Framebuffer Status: GL_FRAMEBUFFER_COMPLETE

Right Eye FBO:
├── Color Attachment 0 → right_eye_texture (1024x768 RGBA)
├── Depth Buffer (generated by glClear)
└── Framebuffer Status: GL_FRAMEBUFFER_COMPLETE
```

### Fullscreen Quad Geometry

```c
Vertex Data (5 floats per vertex = Position XYZ + TexCoord UV):
┌─────────────────────────────────────────┐
│ Position (XYZ)      │ TexCoord (UV)     │
├─────────────────────┼──────────────────┤
│ -1.0, -1.0, 0.0     │ 0.0, 0.0         │ (bottom-left)
│  1.0, -1.0, 0.0     │ 1.0, 0.0         │ (bottom-right)
│ -1.0,  1.0, 0.0     │ 0.0, 1.0         │ (top-left)
│  1.0,  1.0, 0.0     │ 1.0, 1.0         │ (top-right)
└─────────────────────────────────────────┘

Rendered as: GL_TRIANGLE_STRIP
Indices: 0 → 1 → 2 → 3
Result: Two triangles covering full screen
```

## OpenGL State Management

### FBO Binding Sequence

```glsl
// BeginEyeRender(STEREO_EYE_LEFT)
glBindFramebuffer(GL_FRAMEBUFFER, left_eye_fbo);  // Bind FBO
glViewport(0, 0, 1024, 768);                      // Set size
glClearColor(0.0, 0.0, 0.0, 0.0);
glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);

// RenderGame2(0) renders here - goes to left_eye_texture

// EndEyeRender()
glBindFramebuffer(GL_FRAMEBUFFER, 0);             // Back to backbuffer
glViewport(0, 0, 1024, 768);                      // Restore viewport
```

### Texture Binding for Composition

```glsl
// StereoCompositor_RenderFullscreenQuad()
glUseProgram(anaglyph_shader);

// Set texture units
glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_2D, left_eye_texture);
glUniform1i(glGetUniformLocation(shader, "leftEyeTexture"), 0);

glActiveTexture(GL_TEXTURE1);
glBindTexture(GL_TEXTURE_2D, right_eye_texture);
glUniform1i(glGetUniformLocation(shader, "rightEyeTexture"), 1);

// Reset to texture unit 0
glActiveTexture(GL_TEXTURE0);

// Render quad
glBindVertexArray(fullscreen_quad_vao);
glDrawArrays(GL_TRIANGLE_STRIP, 0, 4);
glBindVertexArray(0);

glUseProgram(0);
```

## Shader Implementation Details

### Anaglyph Simple Shader

```glsl
#version 120
uniform sampler2D leftEyeTexture;
uniform sampler2D rightEyeTexture;
varying vec2 v_texcoord;

void main() {
    vec4 left = texture2D(leftEyeTexture, v_texcoord);
    vec4 right = texture2D(rightEyeTexture, v_texcoord);
    
    // Red-cyan: left.R | right.G + right.B
    gl_FragColor = vec4(left.r, right.g, right.b, 1.0);
}
```

**Color Matrix**:
```
[1  0  0] [L.r]   [R_out]
[0  0  0] [L.g] = [G_out]
[0  0  0] [L.b]   [B_out]

[0  0  0] [R.r]   [R_out]
[0  1  0] [R.g] + [G_out]
[0  0  1] [R.b]   [B_out]
```

### Full-Color Anaglyph Shader

```glsl
#version 120
uniform sampler2D leftEyeTexture;
uniform sampler2D rightEyeTexture;
varying vec2 v_texcoord;

void main() {
    vec4 left = texture2D(leftEyeTexture, v_texcoord);
    vec4 right = texture2D(rightEyeTexture, v_texcoord);
    
    // Luminance weights (BT.709 standard)
    float left_lum = dot(left.rgb, vec3(0.3, 0.59, 0.11));
    float right_lum = dot(right.rgb, vec3(0.3, 0.59, 0.11));
    
    // Primary color contribution + secondary spillover
    vec3 result = vec3(
        left.r * 0.8,              // Left red channel (primary)
        right.g * 0.9,             // Right green channel (primary)
        right.b * 0.9              // Right blue channel (primary)
    );
    
    // Add slight luminance from opposite eye for color accuracy
    result += vec3(
        right_lum * 0.1,           // Right luminance spillover to red
        left_lum * 0.1,            // Left luminance spillover to green
        left_lum * 0.1             // Left luminance spillover to blue
    );
    
    gl_FragColor = vec4(result, 1.0);
}
```

**Color Matrix**:
```
[0.8  0   0  ] [L.r]   [0.0  0.1  0.1] [R.r]   [R_out]
[0    0   0  ] [L.g] + [0    0.9  0  ] [R.g] = [G_out]
[0    0   0  ] [L.b]   [0    0    0.9] [R.b]   [B_out]
     +luminance spillover calculations
```

### Side-by-Side Shader

```glsl
#version 120
uniform sampler2D leftEyeTexture;
uniform sampler2D rightEyeTexture;
varying vec2 v_texcoord;

void main() {
    vec2 texCoord = v_texcoord;
    
    if (texCoord.x < 0.5) {
        // Left half of output: left eye
        texCoord.x *= 2.0;  // Scale from [0, 0.5] to [0, 1]
        gl_FragColor = texture2D(leftEyeTexture, texCoord);
    } else {
        // Right half of output: right eye
        texCoord.x = (texCoord.x - 0.5) * 2.0;  // Scale [0.5, 1] to [0, 1]
        gl_FragColor = texture2D(rightEyeTexture, texCoord);
    }
}
```

**Output Layout**:
```
┌────────────────┬────────────────┐
│  Left Eye      │  Right Eye     │
│  (0.0-0.5)     │  (0.5-1.0)     │
└────────────────┴────────────────┘
```

### Interlaced Shader

```glsl
#version 120
uniform sampler2D leftEyeTexture;
uniform sampler2D rightEyeTexture;
uniform vec2 screenSize;
varying vec2 v_texcoord;

void main() {
    // Use screen coordinates to determine scanline parity
    float scanline = mod(gl_FragCoord.y, 2.0);
    
    if (scanline > 0.5) {
        // Odd scanline (1, 3, 5, ...) - left eye
        gl_FragColor = texture2D(leftEyeTexture, v_texcoord);
    } else {
        // Even scanline (0, 2, 4, ...) - right eye
        gl_FragColor = texture2D(rightEyeTexture, v_texcoord);
    }
}
```

**Pixel Layout**:
```
y=0 (even):   [R1] [R2] [R3] ...  (right eye)
y=1 (odd):    [L1] [L2] [L3] ...  (left eye)
y=2 (even):   [R4] [R5] [R6] ...  (right eye)
y=3 (odd):    [L4] [L5] [L6] ...  (left eye)
...
```

## Error Handling

### FBO Creation Failure

```c
// If CreateFramebufferForTexture returns 0:
if (!g_compositor.left_eye_fbo || !g_compositor.right_eye_fbo) {
    // Log warning
    printf("StereoCompositor: Warning - Framebuffer creation failed\n");
    
    // Set fallback flag
    g_compositor.use_render_to_texture = 0;
    
    // Continue with double-render fallback
    // No crash, degraded performance
}
```

### Framebuffer Incomplete

```c
GLenum status = glCheckFramebufferStatus(GL_FRAMEBUFFER);
if (status != GL_FRAMEBUFFER_COMPLETE) {
    // Possible status values:
    // GL_FRAMEBUFFER_UNDEFINED
    // GL_FRAMEBUFFER_INCOMPLETE_ATTACHMENT
    // GL_FRAMEBUFFER_INCOMPLETE_MISSING_ATTACHMENT
    // GL_FRAMEBUFFER_INCOMPLETE_DRAW_BUFFER
    // GL_FRAMEBUFFER_INCOMPLETE_READ_BUFFER
    // GL_FRAMEBUFFER_UNSUPPORTED
    
    printf("Error: Framebuffer incomplete! Status: 0x%x\n", status);
    
    // Clean up and disable RTT
}
```

### Shader Compilation Failure

```c
// If GR_Shader_Compile returns 0:
if (!g_compositor.anaglyph_shader) {
    printf("Error: Failed to compile anaglyph shader\n");
    
    // Set fallback (will not render composition)
    g_compositor.use_render_to_texture = 0;
    
    // Game continues with fallback
}
```

## Thread Safety

**Current**: Single-threaded only
- All rendering calls from main thread
- No mutex protection needed
- PsyX handles thread safety internally

**For Multi-threaded**: Would need:
```c
// Add to STEREO_COMPOSITOR:
pthread_mutex_t state_lock;

// Lock before state changes
pthread_mutex_lock(&g_compositor.state_lock);
g_compositor.use_render_to_texture = 1;
pthread_mutex_unlock(&g_compositor.state_lock);
```
